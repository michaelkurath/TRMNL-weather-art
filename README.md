# Weather Art

*Local weather in the style of famous artists.* A concept for the TRMNL Frame that displays full-screen artwork without weather icons, numbers, or forecasts.

| Setting | Controls |
| --- | --- |
| Scene | The place depicted in the artwork |
| Artist | The visual treatment available for the selected scene |
| Weather location | The location used to retrieve current conditions |

The weather location and the depicted scene are independent. Russikon's weather can drive either the village or the city scene.

| Scene | Available styles |
| --- | --- |
| Small village | Van Gogh, Warhol, Picasso, Neutral |
| Big city | Van Gogh, Warhol, Neutral |
| Mountain Lake | Neutral, applied automatically |

In Big City, **Current city style** uses the style already saved by an earlier version of the recipe, or Van Gogh on a fresh installation. Choose a named style to set it explicitly for Big City.

Each completed weather state has a 2560 × 1440 landscape JPEG and a 1440 × 2560 portrait JPEG. The eight daytime states are clear, overcast, fog, calm rain, windy rain, dry wind, snow, and thunderstorm.

## Install on TRMNL

Download [Weather Art.zip](dist/Weather_Art.zip) and use **Plugins → Private Plugin → Import new** in TRMNL. Set **Scene** and **Weather location**, and choose an **Artist** when the scene offers one. Save and force refresh to see the new selection immediately. Weather location defaults to Zürich.

The recipe polls [Open-Meteo](https://open-meteo.com/) hourly for the current weather code, 10 m wind speed, and day/night flag. Weather data is provided under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Neutral, Van Gogh and Warhol each cover all eight daytime weather states for the village and city. Thunderstorm, snowfall and fog codes select their own scenes. Rain and drizzle use windy-rain art at 30 km/h or above and calm-rain art below that speed. Dry conditions at 30 km/h or above use dry-wind art. Otherwise, overcast has its own scene and clear to partly cloudy conditions use clear art. Missing or unknown weather codes use clear art, and missing wind speed leaves the wind variant off.

All four layouts preserve the artwork's aspect ratio. Full and quadrant layouts follow screen orientation. The horizontal half always uses landscape artwork, and the vertical half always uses portrait artwork. Each weather state has separate portrait and landscape compositions. The portrait Warhol compositions stack their two ink treatments vertically. Differently shaped layouts can have margins.

The GitHub Sync source lives in `src/` at the repository root. When the plugin is linked to this repository in TRMNL, leave its folder setting blank. Use `trmnlp serve` for local preview. After editing the recipe, rebuild the import ZIP from the repository root with `zip -j dist/Weather_Art.zip src/*.liquid src/settings.yml`.

To set the plugin icon, download [weather-art-icon.png](artwork/weather-art-icon.png), click the current icon in the TRMNL private plugin settings, and select the PNG.
